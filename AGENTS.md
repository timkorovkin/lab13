4 агента для HR-автоматизации
Агент 1 — Парсинг резюме (ResumeParserAgent)

Роль: извлекает структурированные данные из резюме
Входные данные: текст резюме (имя, опыт, навыки, образование)
Выходные данные: JSON со структурированными полями кандидата
Бизнес-правила: резюме без опыта работы помечается как junior; обязательные поля — имя и контакт

Агент 2 — Сопоставление с вакансиями (JobMatchingAgent)

Роль: сравнивает профиль кандидата с требованиями вакансий
Входные данные: JSON кандидата от ResumeParserAgent + список вакансий
Выходные данные: список подходящих вакансий с оценкой совместимости (0-100%)
Бизнес-правила: совместимость ≥70% — кандидат проходит дальше; ключевые навыки имеют больший вес

Агент 3 — Планирование собеседований (InterviewSchedulerAgent)

Роль: назначает время собеседования для прошедших отбор кандидатов
Входные данные: список кандидатов с совместимостью ≥70% + доступные слоты времени
Выходные данные: расписание собеседований
Бизнес-правила: кандидаты с совместимостью ≥90% получают приоритетные слоты; не более 5 собеседований в день

Агент 4 — Обратная связь (FeedbackAgent)

Роль: формирует и отправляет обратную связь кандидатам
Входные данные: результат сопоставления + статус собеседования
Выходные данные: текст письма кандидату
Бизнес-правила: отказ отправляется не раньше чем через 24 часа после решения; приглашение содержит детали собеседования
